# Paseo GitHub Workspace live test

This directory is dedicated to live verification of the Paseo plugin.
The profile README at the repository root is intentionally left unchanged.

The CI marker starts as `fail` so the plugin can display a real failed run,
its job and logs, and exercise rerunning failed jobs. It will be changed to
`pass` before the test pull request is merged.

Issues, PR comments, review threads and test sessions are labelled with
`[Paseo live test]` so they can be recognized during manual inspection.

Manual verification follow-up: this PR stays open for checking the Paseo plugin.
